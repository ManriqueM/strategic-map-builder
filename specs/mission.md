# Mission

## Why

Organizations that use the Balanced Scorecard framework need a way to turn their mission,
vision, values, and four strategic perspectives (Financial, Customer, Internal Process,
Learning & Growth) into a visual strategy map — then keep it alive: track which objectives
are on track, see how initiatives connect across perspectives, and update status over time.
Today this typically lives in static slides or spreadsheets that go stale immediately.

This project is a strategy map builder and viewer: a tool to construct a strategy map from a
flexible set of sections, save it, then interact with it — drawing connections between
objectives and color-coding status — so the map stays a living artifact instead of a one-time
diagram.

## Audience

Built as a product to eventually offer to others — individuals or organizations doing
strategic planning who want a lightweight, visual, self-serve way to build and maintain a
strategy map without specialized BI/strategy software.

## Why it exists

- Existing options are either generic diagramming tools (no strategy-map-specific structure)
  or heavyweight enterprise strategy software (expensive, overkill for most teams).
- A focused, opinionated builder — with sensible defaults (mission/vision/values + 4
  perspectives) but room to customize — lowers the barrier to actually maintaining a strategy
  map instead of letting it rot in a slide deck.
